Generated by `python3 tools/idioms.py report` from `build/idioms/db.json.gz` (`tools/idioms.py build` makes it; see the tool's docstring). Do not edit by hand.

Mined from **10699** functions that are C in `src/` and compile with `-g` to retail's code (another 3448 are copies of one of them, the same code in another file or level, and count once; 72 were left out because `-g` changes their code; the 1849 C functions of Sony's library files, built with other compilers, are not compiled), cut into **308478** fragments (one C statement and the instructions gcc made for it, or one inline helper call) of **99885** distinct shapes.

How to read it: an assembly shape has registers as classes numbered in order of appearance (`t1`, `a1`, `v1`, `s1`, `fa1` = $f12-$f19, `fv1` = $f0-$f3, `vf1`), immediates in buckets (`0`, `1`, `s` small, `p2` a power of two, `i16`, `neg`), `%gp`/`%hi`/`%lo` for relocated operands (`+` when the symbol has an offset), `F` a call target, `Lf`/`Lb` a forward/backward branch. A C form has `v` for a local or parameter, `G` a `D_` global, `F` a function, `m` a member, `N`/`Nf` a number. To ask for a block of an unmatched function: `python3 tools/idioms.py query asm/.../func_X.s`.
